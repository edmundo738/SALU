# Demonstração

**Não existe seed de demonstração na aplicação normal.** O SALU arranca com a base vazia.

- Não há bots, scheduler, contas geradas nem avaliações de exemplo.
- A base antiga de demonstração está congelada em `data/archive/salu-demo-2026-11-21.db*` e **não** é carregada.
- Para uma demonstração, criar contas reais e percorrer o ciclo; os dados são reais para quem os cria.
- Nunca atribuir verificação, avaliações ou histórico a contas de demonstração.
